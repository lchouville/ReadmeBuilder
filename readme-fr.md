## ℹ️ Introduction
ReadmeBuilder est un outil web permettant de créer des fichiers README.md structurés et compatibles avec GitHub. Il offre un éditeur basé sur des blocs, la prise en charge de plusieurs pages, l'enregistrement automatique et l'exportation au format Markdown, HTML et JSON, ce qui rend la documentation des projets plus rapide et plus facile pour les développeurs.

## 🛠️ Installation
### Télécharger le dépôt
Clonez ou téléchargez le dépôt depuis [https://github.com/lchouville/ReadmeBuilder.git](https://github.com/lchouville/ReadmeBuilder.git).
